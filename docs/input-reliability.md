# 입력 지연과 버튼 고착 수정 (2026-09-25)

## 확인한 결함

- Linux HID gadget은 이전 USB 전송이 진행 중이면 비차단 write에 EAGAIN을 반환한다. 기존 마우스 코드는 이를 버리고, 키보드는 최종 상태만 재시도하거나 연결 종료 시 해제 보고를 버릴 수 있었다. 소켓 역압으로 오른쪽 버튼 해제 유실을 재현했다.
- 실제 장치 hid.GS2 descriptor는 버튼 usage 1..5를 사용한다. 오른쪽 버튼은 0x02인데 기존 코드는 절대 마우스에 0x04를 보냈다. 동일 클릭을 상대·절대 USB 장치 양쪽으로 중복 전송했다.
- 게이트웨이가 절대/상대 포인터 상태를 따로 관리하여 입력 방식이 바뀌면 누른 버튼이 바뀔 수 있었다. 350ms 강제 해제는 정상적인 길게 누르기와 드래그도 끊었다.
- agent는 TCP payload 전체를 기다리는 동안 HID 재시도를 못 했다. Unicode 키 사이 sleep도 같은 수신 루프를 막았다.
- Progressive 프레임 전송 간격은 40ms인데 대기 계산은 10ms였다. 배포 전 운영 로그에서 5초당 약 33만~54만 번의 flush 시도를 관측했다. 이는 입력과 화면 처리를 공유하는 스레드의 불필요한 부하다.

## 변경

키보드와 포인터 각각 순서를 보존하는 유한 큐를 사용한다. 상대·절대 USB 마우스 보고는 같은 포인터 큐를 사용하고, 다른 USB 장치로 넘어가기 전에 이전 전송 완료를 기다린다. EAGAIN은 실패로 버리지 않고 POLLOUT을 기다린다. 새 입력 없이도 마지막 해제를 전송한다. 버튼 변화가 없는 인접 절대 이동만 합친다. 왼쪽·오른쪽·가운데 버튼과 세로 휠은 상대 USB 장치가 소유하며 게이트웨이 두 포인터 콜백이 상태를 공유한다. 상대 이동 후 버튼 해제 시 이전 절대 좌표를 다시 보내지 않는다. 추가 버튼 4/5와 지원되는 가로 휠만 절대 장치를 사용한다. 상대 이동량은 잘라 버리지 않고 여러 보고로 나눈다.

종료, 연결 해제, 큐 초과, USB 전송 실패 시 오래된 동작을 취소하고 중립 보고를 모든 장치에 재시도한다. 1초 동안 진행이 없는 전송도 같은 복구 경로를 사용한다. 정상적으로 누르고 있는 키와 버튼에는 임의의 시간 제한을 걸지 않는다.

TCP 수신은 부분 프레임을 유지하는 비차단 파서와 최대 32개 메시지 배치를 사용한다. Unicode 키 간격과 클립보드 전달 순서는 출력 큐에서 관리한다. 제어 소켓 쓰기에는 100ms 제한을 두고, 전송 중 실패한 TCP 연결은 닫아 프레임 경계가 깨진 연결을 재사용하지 않는다. 게이트웨이 대기 계산은 실제 코덱 간격을 따르며 입력을 먼저 읽고 화면을 전송한다.

## 검증과 관측

`ctest --test-dir build/host-unit --output-on-failure`로 기존 단위/RTP 테스트와 입력 회귀 테스트를 실행한다. `nanokvm-input-reliability-test`는 USB 역압을 소켓으로 모사한다. 버튼 매핑과 혼합 입력, 마지막 해제, 이동 병합, 수정키 순서와 원형 큐 재사용, 전체 해제, 초과/정지 복구, Unicode 중 클릭, 연속 이모지 붙여넣기 순서, 휠 및 분할 TCP 수신을 검증한다. 실제 키보드나 마우스를 조작하지 않는다.

agent는 5초마다 INPUT 누적 이벤트/전송/재시도/오류/초과 횟수, 키보드/포인터 대기 개수, 최근 구간 최대 큐 대기 및 핸들러 시간을 기록한다. 입력 문자 내용은 기록하지 않는다. 큐 대기 시간에는 의도적인 Unicode 키 간격도 포함되며 USB 호스트 수신 완료나 화면 반영까지의 종단 지연은 아니다. EAGAIN 재시도 횟수 자체는 정상일 수 있다. 오류·초과 증가, 대기 큐가 계속 남는 현상을 점검한다.

자동 회귀 테스트는 확인한 코드 결함의 재발을 검증한다. 일상 사용의 모든 기기·네트워크 조건에서 불편이 사라졌다는 증명과는 구분한다. 특히 USB 자체 분리나 RDP 클라이언트가 보내지 않은 키 해제는 서버가 즉시 알 수 없다.

참고: [Linux 5.10 f_hid 구현](https://github.com/torvalds/linux/blob/v5.10/drivers/usb/gadget/function/f_hid.c), [FreeRDP 3.14 입력 플래그](https://github.com/FreeRDP/FreeRDP/blob/3.14.0/include/freerdp/input.h).
